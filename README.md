# CERDAS-APPLICATION
Platform digital yang membantu orang tua/wali menerima pengingat pembayaran secara proaktif, melihat kewajiban dan riwayat pembayaran, serta menyelesaikan pembayaran; sekaligus memungkinkan kepala sekolah dan staf tata usaha/keuangan memantau penerimaan, umur tunggakan, pengecualian, dan risiko kas operasional.
